# P3-V3-MEF-ALIGN-01 repair evidence map

Date: 2026-08-11

This map establishes infrastructure semantics only. The positive boundary uses two local synthetic subjects and forbids real P12 access and scientific execution. Therefore `authorized_real_p12_job_count=0`, `recorded_real_scientific_terminal_count=0`, and every scientific claim remains `blocked`. A zero count means that no such job or terminal scientific result was authorized or recorded; it is not a scientific finding and makes no claim that a platform capability is physically absent.

The end-to-end boundary is `tests/p3_v3/test_synthetic_phase_path.py::test_two_subject_phase0_to_phase7_path_is_production_verified`. It creates clean Git repositories for Python PEP 517/S and CMake/CTest/M, invokes the real `freeze-authority-lock` CLI, computes the external literal SHA-256 independently from the emitted lock bytes, materializes only lock-derived Phase 0–7 intents, and invokes the real `verify-evidence` CLI with the evidence index, authority lock, and literal digest. No test-side authority or alternate RQ copy is substituted.
