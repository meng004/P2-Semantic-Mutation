# P3-V3-MEF-ALIGN-01 repair evidence map

Date: 2026-08-10

This map proves infrastructure semantics only. It does not report a real P12 access, a real mutant or MR execution, a scientific result, or support for any scientific claim. Every claim remains `blocked`.

The end-to-end boundary is `tests/p3_v3/test_synthetic_phase_path.py::test_two_subject_phase0_to_phase7_path_is_production_verified`. It drives the real production APIs and CLI over a socket-blocked, local-only fixture containing Python PEP 517/S and CMake/CTest/M subjects, Phase 0 through Phase 7 attempt trees and receipts, three package roots, two slots, the four-artifact MR chain, the P12 denominator/results/summary, seven blocked claims, and one byte-indexed evidence index.

## Rehashed mutation inventory

The parameterized synthetic matrix independently rebuilds a complete positive evidence root for each case and recomputes the mutated artifact/index hashes local to the forged node. Production `verify-evidence --index` itself rejects these 22 cases: `adapter_byte`, `adapter_output`, `source_scale`, `schema`, `workload`, `common_input`, `fallback_order`, `technique_label`, `site`, `retry_argv`, `retry_seed`, `event`, `ledger`, `receipt`, `package_byte`, `slot_coordinate`, `mr_parent`, `denominator`, `p12_result`, `p12_summary`, `claim_status`, and `index_membership`.

The composite end-to-end boundary rejects the fully reclosed `origin_receipt` case by rerunning production preflight and comparing the regenerated origin identity. It additionally rejects `completion_metadata` by reconstructing the exact completion record from already verified indexed evidence. In both cases, the test explicitly confirms that `verify-evidence --index` alone returns success before the independent boundary rejects the forgery. Thus the matrix covers the brief's 23 required mutations plus one explicit completion-metadata mutation, for 24 mutation cases total.

## Completion ceiling

At the composite test boundary, the Phase 7 completion artifact must exactly equal the value reconstructed from authenticated indexed evidence: two subjects, two ecosystems, scale classes M/S, no real P12 access, zero real scientific jobs, infrastructure-only semantics, and `claims_status=blocked`. This is not presented as an independent capability of the production final verifier. Synthetic P12 rows exercise missingness accounting only; they are not scientific observations.
