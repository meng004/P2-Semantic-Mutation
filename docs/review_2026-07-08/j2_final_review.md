**F3 — Slot-label nature of the Study-2 pool is never stated in the manuscript (transparency).**
The v5 pools carry per-mutant source tokens `claude`/`gpt`/`deepseek` (e.g. `data/mutants/a1_pool_v5/m04_a1_CE1_deepseek_a03.py`), produced by `cross_source_campaign.py`'s three-slot `FAMILIES=("claude","gpt","deepseek")`. A reviewer auditing `data/mutants/*_pool_v5/` would see competitor-vendor filenames unreconciled with the same-vendor claim; the word "slot" lives only in PILOT_LOG and code comments. Fix = one explicit sentence in §study2-harness or App J.5.
**Important scope limit:** this is a disclosure gap, **not** a verdict-changing flaw.
