An elegant way to construct metamorphic relations of the **MP5 (method-comparison/refinement)** family for this linear solver is to exploit the known mathematical properties of the system. 

Specifically, the output of the program, $f(x) = \sum u(x)$, is a linear function of $x$ and is antisymmetric about $0.5$ (meaning $f(x) + f(1-x) = 0$, so $f(0.5) = 0$). Because of this perfect linearity, any convex combination of inputs yields the exact same convex combination of outputs. 

We can construct refinement relations where the "new" evaluation regime $r(x)$ computes a value whose magnitude is guaranteed to be smaller (closer to the zero-point at $0.5$) or larger in a highly predictable, ordered manner. For example, moving $x$ closer to the symmetry center $0.5$ systematically decreases the absolute value of the output.

Here is the implementation of the metamorphic relations:

```python
import math
import numpy as np

# MP5 (method-comparison): Comparing evaluations under different regimes.
# Since f(x) is linear and antisymmetric about 0.5 (f(0.5) = 0),
# the absolute value |f(x)| is directly proportional to |x - 0.5|.
# We can define input transformations that systematically scale this distance,
# and assert the corresponding relative ordering of the absolute outputs.

def r_1(x: float) -> float:
    """Contraction towards the symmetry center 0.5.
    
    This maps x to a point closer to 0.5, which must reduce the absolute
    value of the output: |f(r_1(x))| <= |f(x)|.
    """
    return 0.5 + 0.5 * (x - 0.5)


def R_1(y_orig: float, y_new: float) -> bool:
    """Asserts that the contracted input produces a smaller absolute output."""
    if not (math.isfinite(y_orig) and math.isfinite(y_new)):
        return False
    return abs(y_new) <= abs(y_orig) + 1e-12


def r_2(x: float) -> float:
    """Expansion away from the symmetry center 0.5 towards the boundaries.
    
    This maps x to a point further from 0.5, which must increase the absolute
    value of the output: |f(r_2(x))| >= |f(x)|.
    """
    # Project x to be further from 0.5, staying within [0, 1]
    return 0.5 + 2.0 * (x - 0.5) if abs(x - 0.5) <= 0.25 else x


def R_2(y_orig: float, y_new: float) -> bool:
    """Asserts that the expanded input produces a larger or equal absolute output."""
    if not (math.isfinite(y_orig) and math.isfinite(y_new)):
        return False
    return abs(y_new) >= abs(y_orig) - 1e-12


def r_3(x: float) -> float:
    """A fixed contraction ratio of 0.1 towards the symmetry center 0.5.
    
    This reduces the distance to 0.5 by exactly a factor of 10, meaning
    the output magnitude should also scale down by approximately 10.
    """
    return 0.5 + 0.1 * (x - 0.5)


def R_3(y_orig: float, y_new: float) -> bool:
    """Asserts that the scaled input produces a proportionally scaled output."""
    if not (math.isfinite(y_orig) and math.isfinite(y_new)):
        return False
    # |y_new| should be approximately 0.1 * |y_orig|
    return abs(abs(y_new) - 0.1 * abs(y_orig)) <= 1e-11
```
