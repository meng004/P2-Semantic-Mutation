1. **Self-inverse reflection / Point Symmetry**: The transformation $r_1(x) = 1 - x$ reflects the input domain. The corresponding outputs must satisfy $I(x) + I(1-x) = 8/3$ exactly, which represents a conservation of the sum (a shape trajectory that mirrors across the center $x = 0.5$).
2. **Translation / Shift**: A constant shift in the input $r_2(x) = x + c$ (for a valid range) translates the output by exactly $2c$. This preserves the linear shape and slope of the trajectory.
3. **Scaling**: Scaling the input relative to a fixed point preserves the linear scaling factor of the output.
