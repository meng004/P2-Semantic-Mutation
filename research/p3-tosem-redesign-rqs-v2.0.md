## 1. 论文身份（唯一旗舰主张）

> SMS 是一个对"MR 集合相对声明语义层的充分性"**健全（区间意义）、可归因、可经验校准**的度量：其形式性质由退化定理与对偶理论保证，其缺口可分解为对齐残余与强度残余，其预测可在准入解耦的真实缺陷样本上盲测校准。

- 在四柱体系中的位置：SMS = T3 检测矩阵 B 在"声明不变量族 I"上的可计算限制；语义变异体 = 四柱 §3.4/§5.7 的"受控注入缺陷"真值锚的可批量合成形式。P3 为 T2/T3 的证伪实验提供测量仪器，不与四柱争理论地盘。
- 不再主张：跨项目工业有效性、优于语法变异、真实缺陷检测优越性。

## 2. 理论深化：定理群设计（核心增量）

现有 Theorem 1（Rice 常规）、Theorem 2（近定义）、Theorem 9.1（代入一致性）深度不足。新增四个非平凡且可证的结果，全部消费现有构造（fiber、S1–S5、strong/weak、latency window、certificate-first），不引入新本体。

### Thm A：SMS 区间健全性与单调性〔待证，难度低〕

**陈述草案**：设 n 为 CONFIRMED_NON_EQUIVALENT 数，k 为其中被杀数，u 为 EQUIVALENCE_UNRESOLVED 存活数（引理：被杀即获非等价见证，故 unresolved 被杀项自动升格为 confirmed，unresolved 中只剩存活者）。则真实 SMS ∈ [k/(n+u), k/n] = [SMS_cons, SMS_strict]；区间宽度 ≤ f(u/n)；每张新证书单调收窄区间；MR 集合扩张下两端点均单调不减（(k+1)/(n+1) ≥ k/n 恒成立）。

**价值**：把"strict/conservative 双口径"从报告惯例升格为健全性定理；给"证书预算 ↔ 度量精度"一个可计价的交换关系。审稿人无法指责区间报告是 hedging——它是定理要求。

### Thm B：缺口归因定理（对齐残余 ⊕ 强度残余）〔待证，核心〕

**陈述草案**：设变异体满足 S5 层纯性、MR 为其不变量的精确检查器（strong，violation set 对 ≡_α 封闭）。则 kill matrix 按 fiber 呈块对角：跨层 kill 预测为 0。于是

1 − SMS(R) = **对齐残余**（R 未覆盖的 fiber 质量；加对齐 MR 可消除，对应 T3 的 Ω_sel）+ **强度残余**（已对齐 fiber 内的存活质量；对应声明层内的检测力缺口），

且两者仅凭 kill matrix + fiber 标签即可分离。观测到的块外 kill 是"纯性缺陷或 MR 非精确性"的可测偏差量。

**价值**：(a) 这是 SMS 与四柱 T3 三层残余分解的正式对接，理论深度的主要来源；(b) **推论：cross/非对齐 MR 的 SMS 预测为 0** —— 60-cell 的零膨胀和 cross 中位数 0 从"负结果"翻转为"理论预测得到确认的部分"；(c) 给 RQ4 的两部分 estimand 提供推导来源。

### Thm C：容差索引的检测窗定理〔待证，中等难度〕

**陈述草案**：对违反幅度 ε_m 的层 ψ 变异体与边际 μ_r = ε_tol − 正确程序残差 > 0 的强 MR r，在 Lipschitz 观测与噪声界 η 下：ε_m > ε_tol + η + 离散残差 ⟹ 必杀；ε_m < ε_tol − η ⟹ 必不杀；配合 crash 上界得检测窗 (ε_lo, ε_crash)。**推论 1**（弱 MR 假阳性）：μ_r < 0 时正确程序自身被标记。**推论 2**（随机程序假阴性）：η 随统计方差膨胀、按 N^{-1/2} 收缩，给出重复次数处方。

**价值**：把现有 boundary cases（PINN 弱 MR FP、RNG FN）从轶事升格为定理实例；与 v3.1 误差预算分解（τ_disc/τ_stat/τ_round）直接对接；产生**剂量反应预测**（kill 概率随 ε_m 单调）——构念效度验证的经典武器。

### Prop D：可辨识性（逆对偶）〔待证，难度低〕

**陈述草案**：在 Thm B 的块结构下，fiber 隶属可由 kill signature 辨识，粒度为检测矩阵的等价类；若 MR 族含每个不变量的分离检查器（separating family），辨识精确。LRCA 的角色重定义为：标注对块对角结构的偏离。

**价值**：正面回答"定向合成 + 对偶定理能否解释 MR 侧—缺陷侧对应"的**逆方向**（从检出模式反推缺陷层），此前只有正方向。

### 对 Thm 9.1 的修补（既有义务）

- "almost everywhere"在浮点离散域上的表述改为有限例外集/测度陈述二选一；
- L 的连续极限与离散开关分开陈述（L_lim 与 L_switch 两段式）；
- 独立形式审计（与实证作者隔离），审计报告入 Appendix。

## 4. 构念效度重建（解决"证据为负"）

**诊断**：旧 H1–H4 失败的结构原因是假设与理论错配——H2 在含理论预测零质量的混合分布上检验 pooled Cliff's δ；H1 把 class-targeted 算子的"不适用"计为"失败"。

**方案（三件套）**：

1. **理论派生假设**。新假设全部从定理推导：Thm B ⟹ cross cell 预测零（作为分类预测检验，不进 δ）；适用矩阵 ⟹ 实例化域；Thm C ⟹ 剂量反应曲线。构念效度的主终点从"效应够大"改为"**构念能预测**"（预测准确率 vs 多数类基线），对齐四柱 SQ2 盲测纪律。
2. **两部分 estimand**。P(SMS>0) 用对齐性 logistic（hurdle 第一部分）；E[SMS | SMS>0] 用 beta 回归/Wilcoxon（第二部分）。分别预注册效应与功效（模拟法定功效，PUT 级聚类）。功效增量优先来自 MR 集合复制（held-out source 对称协议）与 applicable cell 内变异体加密，而非盲目加 PUT。
3. **剂量反应实验（E3c）**。2 个参数化算子（如 HP 幅度）× 4 PUT，幅度扫描，检验 kill 概率单调性。成本低，是"SMS 测的是声明语义扰动"的最直接构念证据。

**双重使用防火墙**：旧 60-cell 数据只用于冻结适用矩阵与精确性估计（development），确认性检验全部用新生成变异体 + held-out MR source。旧 H1–H4 以"prior audit"身份原样报告。

## 5. 外部效度重建（解决"断链"）

**诊断**：D0 循环 = 准入条件含"MR-discriminating oracle"，用"MR 能判别"筛出的缺陷验证"MR 判别力"。P12 D1 链死于工程可行性，不可复活为 P3 的前提。

**方案（准入反转 + 2×2 盲测）**：

1. **准入解耦**。新验证切片的准入条件只含：真实缺陷 + 双臂可复现 + in-scope（紧凑数值核）。**MR 可检出性从准入条件改为观测结果**——这一步反转直接消除循环，并天然产生 OUT_OF_SCOPE 质量（理论边界的诚实估计）。来源：Defect4MR 64 候选池按新条件重裁 + 少量新挖掘；目标 n ≥ 20 缺陷、≥ 8 项目。新 lineage、pilot 标记，不触碰 P12 封存历史。
2. **2×2 角色分离**。35 个 verified_full = development/校准（D0，披露选择偏差）；新切片 = validation，冻结前不接触。
3. **盲化 fiber 映射**。两名独立标注者在不见 kill 结果条件下做缺陷 → fiber 映射（DIRECT/ADJACENT/OUT_OF_SCOPE/UNCERTAIN），要求 κ ≥ 0.6；主分析仅用 DIRECT（复用 P-series 已规划的 LRCA 二评者资源）。
4. **冻结预测协议**。执行前按 fiber 对齐 + Thm C 窗口冻结每对 (defect, MR set) 的检出/漏检预测与每个 MR 集的 SMS 排序预测；执行后报告：(i) 校准（accuracy/Brier），(ii) 合成变异体 SMS 排序 vs 真实缺陷检出排序的项目等权 Kendall τ，(iii) OUT_OF_SCOPE 份额。
5. **主张边界**。只主张"在准入解耦的紧凑科学核样本上的一致性/校准"，不主张工业外推。TOSEM 接受有界主张 + 干净设计。

## 6. 治理门禁（顺序执行，前项不过不启动后项）

1. SSOT 冲突修复（v4 δ=0.314 vs 0.4392）：结果脚本重生 JSON → CI 比对 manuscript 数字 → 冲突阻断构建。
2. 定理群成文 + 独立形式审计（Thm A/B/C/D + 9.1 修补）。
3. 预注册包冻结：适用矩阵、两部分假设与 MID、剂量反应设计、外部切片准入条件、fiber 映射协议、全部分析代码。
4. E2/E3（构念线）执行。
5. E4（外部线）执行：准入 → 盲映射 → 冻结预测 → 执行 → 揭盲。
6. 论文数字全部由 SSOT 模板注入。

## 7. 风险与预注册降级路径

| 风险 | 概率 | 降级路径（预注册） |
|---|---|---|
| C-H1 再失败（applicable cell 实例化率 < 0.5） | 中 | 论文身份降为"构念可定义 + Thm B 归因的负结果论文"，判别与外部线降 Appendix；理论包独立成立 |
| 剂量反应不单调 | 低 | Thm C 前提（Lipschitz/噪声界）失效诊断进 Threats，构念效度只靠零预测部分 |
| 外部 τ ≈ 0 或校准差 | 中 | 主张收缩为"合成充分性与真实检出在本样本不一致"，以 Thm B 归因解释哪一残余主导；仍是可发表的有界效度结果 |
| 两评者 κ < 0.6 | 低 | 映射协议迭代一轮后重测；仍不达则 DIRECT 主分析降为敏感性分析 |

**关键设计属性**：每条 RQ 的"负向答案"都有预注册的可发表叙事——论文不依赖任何单一正结果，这正是 TOSEM 稳定接收所需的抗审稿鲁棒性。
